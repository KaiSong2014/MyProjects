# 综合报价系统落地页

纯静态中文介绍页与浏览器本地报价体验。页面包含三个可切换的首屏演示、输入输出说明，以及文档读取、手动整理、参数计算、清单预览与下载。

## 在线地址

部署后地址：<https://kaisong2014.github.io/MyProjects/>

## 本地预览

在本目录启动任意静态服务器，例如 `python3 -m http.server 8765`，通过浏览器打开服务器地址。模块脚本需要通过本地服务器运行。

## 体验能力与边界

- 支持 UTF-8 编码的 `.txt`、`.md` 与文字型 `.docx`，单份不超过 5 MiB，正文不超过 50,000 字符。
- 扫描件、旧版 `.doc`、PDF 和图片识别不在首版范围内。
- 本地提取文字后，由用户确认本期功能、工种、费率、工时、采购参数与税率。页面没有接入模型，不能自动完成项目经理级需求分析。
- 五种示例使用明确标注的需求节选和测试参数。工时是演示假设，价格不代表市场行情。自己的文档不会沿用示例费率或税率。
- 文档和编辑内容只保存在当前页面内存中，不发送到服务器，不写入本地持久存储。刷新页面前请下载需要保留的报价。
- 人工和采购按各行金额四舍五入到分；税额按每个税组的未税总额计算。缺失数值不会当作零，税率可明确输入零。
- 导出 `.xlsx` 保留人工、模块合计、税前与税后总价公式。同名模块归并，名称与合计同步合并；只生成一张“报价清单”。
- 采购数量和价格写入备注与采购金额公式，人工单价及工时留空。导出后修改采购参数需修改该采购金额公式；人工和税率可直接修改对应输入格。
- 每条描述最多 400 字，备注最多 350 字。必要时将长需求拆为独立可验收条目。

## 发布方式

在仓库设置的 Pages 中选择：从分支部署 → `main` → `/docs`。该目录已包含 `.nojekyll`，无需安装依赖或构建。

## 第三方组件

仅使用随页面一同托管的 JSZip 3.10.1 进行办公文档解压与报价文件打包，采用 MIT 许可，许可原文保存在 `vendor/LICENSE.txt`。运行时不依赖外部脚本、字体、分析服务或接口。
